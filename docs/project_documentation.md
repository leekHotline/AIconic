# AIconic 项目详细文档

## 1. 项目背景与价值

### 1.1 问题陈述
当前市面上的AI图标生成工具普遍存在以下问题：
- 操作流程繁琐，需要填写大量配置选项
- 生成结果难以迭代修改，用户需要重新开始
- 无法精准理解用户需求，生成结果与预期偏差大
- 风格选择有限，缺乏个性化定制能力

### 1.2 市场/需求分析
- 独立开发者、创业团队数量持续增长，对快速生成专业图标的需求旺盛
- 设计外包成本高、周期长，小团队难以承受
- 现有工具学习成本高，非设计背景用户难以上手
- 多平台适配需求增加，需要批量生成不同尺寸图标

### 1.3 解决方案概述
AIconic 通过自然语言交互，让用户只需一句话描述需求，即可在10秒内生成专业App图标。支持AI理解需求进行多轮迭代修改，配合社区风格插件生态，满足个性化定制需求。

## 2. 技术实现

### 2.1 技术栈
- **前端**：Next.js 14、React 18、TypeScript、Tailwind CSS
- **后端**：Next.js API Routes、Node.js
- **数据库**：PostgreSQL + Drizzle ORM
- **部署环境**：Vercel / Docker
- **主要依赖库**：
  - AI图像生成：Stable Diffusion API / DALL-E API
  - 用户认证：NextAuth.js
  - 状态管理：Zustand
  - UI组件：Radix UI

### 2.3 核心功能模块
1. **自然语言解析模块**：解析用户输入的自然语言描述，提取图标风格、颜色、主题等关键信息
2. **图标生成引擎**：调用AI模型生成符合需求的图标，支持多种风格和尺寸
3. **迭代优化模块**：基于用户反馈进行多轮修改，逐步逼近用户期望
4. **风格插件系统**：支持用户创建、分享和使用自定义风格模板
5. **多平台适配模块**：一键导出iOS、Android、Web等多平台所需的图标尺寸

## 6. 部署说明

### 6.1 最低系统要求
- Node.js >= 18.0.0
- PostgreSQL >= 14
- 内存 >= 2GB
- 存储 >= 10GB

### 6.2 一步步部署指南
```bash
# 1. 克隆项目
git clone https://github.com/leekHotline/AIconic.git
cd AIconic

# 2. 安装依赖
npm install -g pnpm
pnpm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填写数据库连接和API密钥

# 4. 初始化数据库
pnpm run db:migrate

# 5. 启动服务
pnpm dev        # 开发环境
pnpm build && pnpm start  # 生产环境
```

### 6.3 环境变量配置
```env
DATABASE_URL=postgresql://user:password@localhost:5432/aiconic
NEXTAUTH_SECRET=your_secret_key
AI_API_KEY=your_ai_api_key
```

### 6.4 常见问题解答
- **Q: 数据库连接失败？** A: 检查DATABASE_URL配置和PostgreSQL服务状态
- **Q: 图标生成超时？** A: 检查AI_API_KEY是否有效，网络是否通畅
